# אזכרת שרה בת מרים — אתר סטטי ל-GitHub Pages

## מבנה הפרויקט

```text
azkarat-sara/
├── index.html
└── photos/
    ├── photos.json
    └── (קובצי התמונות)
```

## הוספת תמונות

1. העתיקו תמונות לתיקייה `photos`.
2. פתחו את `photos/photos.json`.
3. הוסיפו את שמות הקבצים, הכיתוב והטקסט החלופי, לדוגמה:

```json
[
  {
    "src": "sara-01.jpg",
    "alt": "סבתא שרה מחייכת בגינה",
    "caption": "רגע משפחתי אהוב"
  },
  {
    "src": "sara-02.webp",
    "alt": "סבתא שרה עם בני המשפחה",
    "caption": "עם המשפחה"
  }
]
```

שמות הקבצים רגישים לאותיות גדולות/קטנות. מומלץ להשתמש בשמות באנגלית, ללא רווחים.

## פרסום ב-GitHub Pages

1. העלו את תוכן התיקייה `azkarat-sara` אל ה-repository.
2. ב-GitHub היכנסו ל-Settings → Pages.
3. תחת Build and deployment בחרו Deploy from a branch.
4. בחרו את branch הראשי ואת `/ (root)`, ושמרו.
5. לאחר הפרסום, האתר יהיה זמין בכתובת GitHub Pages של ה-repository.

## הערות

- האתר סטטי; אין שרת ואין שמירת מידע אישי.
- הגלריה נטענת מתוך `photos/photos.json`.
- קישורי תהילים ומשניות נפתחים באתר ספריא, ולכן קריאה מלאה שלהם דורשת חיבור לאינטרנט.
- כפתור ההדפסה מאפשר להדפיס או לשמור PDF דרך הדפדפן.
- לפני שימוש משפחתי, מומלץ לעבור על נוסחי התפילה והמנהגים עם רב המשפחה, במיוחד אם יש מנהג קהילתי מסוים.
